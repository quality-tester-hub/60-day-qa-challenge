# Evidence: Search Placeholder Clipped on Mobile

- **Page:** `https://www.kaggle.com/competitions`
- **Viewport:** 320 × 720 CSS pixels
- **Capture:** Browser screenshot of the public page while logged out
- **Observation:** The “Search competitions” placeholder is visibly clipped in the search field beside **Filters**.
- **Comparison:** At 390 CSS pixels wide, the input is approximately 186 px wide and the placeholder fits. In the 320 × 720 capture, the input is approximately 126 px wide while the placeholder text measures approximately 136 px.
- **Privacy:** No user account or private data is shown.
