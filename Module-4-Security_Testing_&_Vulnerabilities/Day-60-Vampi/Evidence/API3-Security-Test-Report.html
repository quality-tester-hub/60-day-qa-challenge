Key Findings

CRITICAL — Plaintext Passwords via Unauthenticated Debug Endpoint

/users/v1/_debug returns HTTP 200 with no authentication required. All 3 user records are returned with plaintext passwords (pass1, pass2), emails, and admin role flags. This endpoint must be removed or gated behind admin authentication.

HIGH — Email PII Exposed on Public User List

/users/v1 returns email addresses for all 3 users (including admin) with no authentication. Only username should be returned from a public listing endpoint. Property-level response filtering is absent.

HIGH — Admin Role Enumerable

The admin boolean field in the _debug response allows attackers to identify privileged accounts for targeted attacks.

NOTE — Script Error on Hash Detection Test

One test on /users/v1/_debug threw a TypeError (pm.expect(...).to.be.false is not a function). The assertion should use .to.equal(false). This can be fixed without affecting the other results.
